# Fontes não distribuídas

Esta pasta deve receber os 24 arquivos CSV compatíveis para execução local. As fontes originais não acompanham a versão pública porque podem conter dados identificáveis e material de uso restrito.

O inventário esperado, os campos e os relacionamentos estão documentados em `docs/DATA_DICTIONARY.md` e `deliverables/01_EDA/tables/table_inventory.csv`.
