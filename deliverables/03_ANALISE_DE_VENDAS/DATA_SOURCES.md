# Bases utilizadas

Esta análise utiliza diretamente as seguintes fontes:

- `../../data/raw/orders.csv`
- `../../data/raw/order_items.csv`
- `../../data/raw/product_variants.csv`
- `../../data/raw/products.csv`
- `../../data/raw/categories.csv`
- `../../data/raw/brands.csv`
- `../../data/raw/returns.csv`
- `../../data/raw/return_items.csv`

As transformações dbt e os marts são construídos em um DuckDB temporário durante a execução.
